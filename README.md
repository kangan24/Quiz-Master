# 🤖 Quiz Master

An AI-powered quiz generator built with Streamlit and Google Gemini.

## Features

- Generate quizzes on any topic
- Easy, Medium, Hard difficulty levels
- Instant scoring
- AI-generated feedback
- Quiz history tracking
- Performance statistics dashboard

## Tech Stack

- Python
- Streamlit
- Google Gemini API
